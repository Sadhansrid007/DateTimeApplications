### Mini Apps & Games Collection

Welcome to my portfolio repository! This project is a curated collection of interactive mini-games, utility applications, and tools that showcase my programming logic, frontend development, and problem-solving skills. 

### 🚀 Projects Overview

### 🦖 Dino Love Game

An interactive, playful game inspired by the classic pixelated dinosaur runner, modified with unique mechanics and a romantic or lighthearted theme. 

* **Key Features:** Collision detection, score tracking, responsive controls.
* **Tech Used:** HTML5, CSS3, JavaScript.

### 🐦 Flappy Bird Clone

A complete recreation of the famous arcade mobile game where players navigate a bird through a series of incoming obstacles. 

* **Key Features:** Physics simulation (gravity and upward thrust), procedural obstacle generation, high-score memory.
* **Tech Used:** HTML5 Canvas / JavaScript.

### 📊 SGPA Calculator

A highly practical utility tool designed for university students to quickly calculate their Semester Grade Point Average. 

* **Key Features:** Dynamic row insertion for multiple subjects, automatic grade-to-point conversion, accurate weighted average calculations.
* **Tech Used:** JavaScript, Form Validation, CSS Grid/Flexbox.

### ⏱️ Date-Time Applications

A suite of time-management utilities including custom clocks, countdown timers, or time-zone converters. 

* **Key Features:** Live DOM updates, precise interval tracking, timezone API integration.
* **Tech Used:** JavaScript Date Objects, Async functions.
